# Rishi Portfolio — Full-Stack Digital Transformation Engineer

The **Rishi Portfolio** is a premium, high-performance personal showcase of engineering-led digital products, architectural design, and creative content. It serves as the central hub for the work of **Rishikesan**, a Full-Stack Digital Transformation Engineer based in Sri Lanka.

## 🌟 Key Features
- **Dynamic Project Filtering**: Categorized project showcase with real-time filtering for Web, Mobile, and Full-Stack solutions.
- **Glassmorphic UI**: Modern, state-of-the-art aesthetic with smooth transitions and theme-aware components.
- **Multi-Channel Contact Engine**: Integrated "Request Demo" modal supporting direct WhatsApp, Gmail Web, and System Email dispatch.
- **Responsive Engineering**: Fully optimized for mobile, tablet, and desktop viewing.
- **Asset Showcase**: High-quality project galleries featuring construction milestones and software UI.

## 🛠️ Technical Stack
- **Core**: Semantic HTML5 and modern CSS3 (Vanilla).
- **Logic**: Vanilla JavaScript (ES6+).
- **Animation**: Custom CSS transitions and state management.
- **Theme**: Advanced CSS Variable system for Dark/Light mode synchronization.
- **Icons**: [Lucide](https://lucide.dev/) and [Font Awesome](https://fontawesome.com/).

## 📁 Repository Structure
- `index.html`: The main single-page application structure.
- `css/style.css`: Comprehensive design system and responsive styles.
- `js/script.js`: Core interactivity, modal management, and dispatch logic.
- `assets/`: Optimized media assets including project images and branding.

## 🚀 Deployment & Subdomains
The portfolio is designed to be hosted at **www.rishiware.com**, serving as the gateway to a network of project-specific subdomains (e.g., `ridesync.rishiware.com`, `primeware.housefix.lk`).
